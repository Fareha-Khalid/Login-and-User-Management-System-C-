# Login and User Management System (C++)

This is a console-based application built in C++ that allows users to register, log in, and manage user accounts. It was developed as a Data Structures & Algorithms (DSA) project.

## 🔑 Features
- User Registration
- User Login Authentication
- Display Registered Users
- Search for a User
- Delete a User
- Exit Option with Loop Control

## 🧠 Concepts Used
- Classes and Objects
- Vectors (`std::vector`)
- Strings and Input Validation
- Loops and Conditional Statements

## 📸 Sample Interface (Console)
```
WELCOME TO LOGIN PAGE
-------------------------
1. REGISTER
2. LOGIN
3. SHOW USER LIST
4. SEARCH USER
5. DELETE USER
6. EXIT
```

## 📁 How to Run
1. Copy the `.cpp` file into your local machine.
2. Compile using a C++ compiler:
   ```bash
   g++ -o user_system "Login and User Management System.cpp"
   ./user_system
   ```
3. Follow the menu prompts in the console.
